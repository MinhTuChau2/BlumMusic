#  Gesture-Controlled Music Web App  
React + Vite

An interactive web application for making music using hand gestures, voice effects,
and live audio processing. The webcam tracks hand movements to control vocal effects
in real time, while chord loops, BPM control, and recording tools enable creative
performance.



##  Features

###  Hand Gesture & Keyboard Controls

| Gesture / Input | Effect |
|-----------------|--------|
| Fist            | Compression |
| Open Hand       | Echo |
| 1               | Autotune |
| 2               | Radio Effect |
| 3               | Reverb |


###  Music & Audio Tools
- Chord loop playback
- Adjustable BPM (tempo)
- Live vocal input with real-time effects
- Record button to capture performances


##  Tech Stack
- React
- Vite
- JavaScript
- Web Audio API / Tone.js
- Webcam hand tracking
- CSS


Navigate into the project directory:
npm run dev
